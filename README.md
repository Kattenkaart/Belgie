# 🐱 KattenKaart België

**Buurt Katten Spotter** — registreer je katten, volg hun territorium en spot buurkatten op de kaart.

🌐 **Live app:** [kattenkaart.github.io/Belgie](https://kattenkaart.github.io/Belgie/)  
📘 **Facebook:** [KattenKaart België](https://www.facebook.com/profile.php?id=61590245620181)

---

## Wat is KattenKaart?

KattenKaart is een gratis community-app voor kattenliefhebbers in België. Het idee ontstond vanuit een eenvoudige vraag: *waar zwerft mijn kat eigenlijk naartoe?*

Met KattenKaart kan je:
- 🏠 Je eigen katten registreren met foto, ras en adres
- 📍 Spottings melden van katten die je in de buurt ziet
- 🗺️ Het territorium van katten volgen op de kaart
- 🚨 Vermiste katten melden aan buurtbewoners
- ✅ Spottings bevestigen of afwijzen als eigenaar

---

## Hoe gebruik je de app?

1. Ga naar [kattenkaart.github.io/Belgie](https://kattenkaart.github.io/Belgie/)
2. Maak een gratis account aan
3. Registreer je kat(ten) met foto en adres
4. Klik op de kaart om je locatie in te stellen
5. Zie welke katten er in jouw buurt wonen!

Geen app nodig — werkt gewoon in de browser op gsm of computer.

---

## Technisch

Gebouwd als een **single-file PWA** (Progressive Web App):

- **Frontend:** HTML, CSS, Vanilla JavaScript, Leaflet.js (kaarten)
- **Backend:** Supabase (PostgreSQL database + opslag)
- **Hosting:** GitHub Pages (gratis, onbeperkte bandbreedte)
- **Kaarten:** OpenStreetMap
