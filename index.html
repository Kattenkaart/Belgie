Privacybeleid

KattenKaart België — Laatst bijgewerkt: mei 2025

Welke gegevens verzamelen we?

  • Gebruikersnaam en gehashed wachtwoord
  • E-mailadres (optioneel, alleen voor meldingen)
  • Thuisadres van katten (straatnaam + stad, huisnummer verborgen voor publiek)
  • Foto's van katten en spottings
  • Locatiegegevens van spottings

Waarom?

  • Om katten te kunnen registreren en terugvinden
  • Om eigenaren te verwittigen bij een spotting (via e-mail)
  • Om jouw sessie te bewaren (localStorage)

Hoe lang bewaren we het?

Zolang je account actief is. Je kan je account en alle bijbehorende data op elk moment verwijderen via Instellingen → Account verwijderen.

Delen we data met derden?

Nee. Data wordt opgeslagen via Supabase (EU-servers, Ierland) en foto's via Supabase Storage. Geen advertenties, geen tracking.

Jouw rechten (GDPR)

  • Recht op inzage van jouw data
  • Recht op verwijdering (account verwijderen)
  • Recht op correctie (profiel bewerken)

Contact

Vragen over privacy? Stuur een bericht via de app of open een GitHub issue op Jana191997/Kattenkaart.
